This are code general Guidelines for operator and agents working on this project:
- Each class, struct or enum ecc. goes into separate file.cs named accordingly.
- Classes and methods should have complete documentation.
- Naming convention should be compliant with language standards
- Namespaces and folders have to be consistent and compatible.
- No emoji, nowhere, never in code or documents, allowed only in chat.
- When it's possibile to create abstractions and virtuals it's preffered to leave the code as modular as possibile (for future review and modification.)
